# Сайт «Ремонт квартир под ключ»

Одностраничный лендинг с калькулятором, прайсом и портфолио. Собран с нуля по трём референсам
заказчика. Пока это «кости»: структура, логика и вёрстка готовы, вместо реальных фото и контактов —
заглушки, которые правятся в одном месте.

## Запуск

```bash
npm install
npm run dev
```

Дев-сервер: http://localhost:5180. Сборка в статику — `npm run build`, результат в `dist/`
(заливается по FTP на любой обычный хостинг, Node на проде не нужен).

## Из чего состоит

| Папка | Что это |
|---|---|
| корень | публичный сайт — Vite 6 · React 19 · TypeScript · Tailwind 4 |
| `server/` | API и база: Node · Express · SQLite. Заявки, контент, статистика, Telegram |
| `admin/` | админка — тот же стек, что и сайт; собирается в `server/public/admin` |

Сайт умеет работать **без сервера**: если `VITE_API_URL` пуст, контент берётся из `src/data`,
а заявки складываются в `localStorage`. Так он и живёт сейчас на GitHub Pages.

Запуск всего сразу и выкладка на VPS — в [DEPLOY.md](DEPLOY.md).

## Публичная версия

Сайт выложен на GitHub Pages: **https://qt1995.github.io/remont/**

Обновить после правок — одна команда:

```bash
npm run deploy
```

Она собирает сайт с базовым путём `/remont/` и force-push'ит папку `dist` в ветку
`gh-pages`. Исходники живут в `main`, сборки историю не засоряют.

Базовый путь нужен потому, что репозиторий называется не `qt1995.github.io`, а `remont` —
значит это не пользовательский сайт, а проектный, и он лежит в подпапке. Путь задаётся
один раз в `vite.config.ts` (`PAGES_BASE`), адрес репозитория — в `scripts/deploy-pages.mjs`.

## Концепция

Сайт продаёт не «ремонт», а **предсказуемость**. Все три референса говорят «под ключ, качественно,
недорого» — на этом фоне выигрывает тот, кто первым покажет цифры и признает риски вслух.

Отсюда три опоры:

1. **Прозрачность.** Прайс на 42 позиции прямо на странице, тарифы с честным разделением «работы» и
   «работы + материалы», калькулятор, который выдаёт вилку, а не одну красивую цифру.
2. **Снятие страхов.** Отдельный блок «чего боятся все, кто заказывает ремонт»: сорванные сроки,
   растущая смета, пропавшая бригада. Каждый страх закрыт пунктом договора, а не лозунгом.
3. **Наглядность этапов.** Слайдер «черновая → чистовая → с мебелью» на одной и той же комнате —
   объясняет, за что платят на каждом шаге, и естественно подводит к допродаже комплектации.

Тон: спокойный, без капса и «АКЦИЯ ТОЛЬКО СЕГОДНЯ». Палитра — тёмно-синий (доверие) + приглушённое
золото (премиальность) на тёплом песочном фоне.

## Структура страницы

1. **Герой** — цена от, четыре гарантии, две кнопки (расчёт / консультация), счётчики.
2. **Этапы наглядно** — тройной слайдер до/после.
3. **Тарифы** — вкладки «Новостройка / Вторичка», 3–4 пакета, что входит и чего нет, пример на 50 м².
   Отдельным баннером — комплектация мебелью (+10 000 ₽/м²).
4. **Калькулятор** — 7 шагов, живой пересчёт, вилка ±10%, срок, разбивка по статьям.
5. **Прайс-лист** — 7 групп работ, поиск по основе слова, запрос PDF-прайса.
6. **Наши работы** — фильтр по типу, площадь / срок / бюджет по каждому объекту. Ниже — блок про
   3D-визуализации до начала стройки.
7. **Боли клиентов** — 6 страхов и ответ на каждый.
8. **Как работаем** — 6 этапов с длительностью.
9. **Гарантии и акции** — 4 пункта договора + 3 акции.
10. **Отзывы** — видео (заглушки под съёмку) + текстовые.
11. **FAQ** — 8 развёрнутых ответов.
12. **Контакты** — телефон, почта, мессенджеры, честная формулировка про офис + форма.

Сквозные элементы: липкая шапка с переключателем города, модалка заявки на каждой кнопке, нижняя
панель с CTA на мобильных.

## Где что править

Когда сервер подключён, **всё содержимое правится через админку** — в код лезть не нужно:
тарифы, прайс, работы с фотографиями, кадры для слайдера этапов, боли, этапы работы, гарантии,
акции, отзывы, вопросы, контакты, города и коэффициенты цен.

Файлы в `src/data` остаются запасным вариантом: с них наполняется база при первом запуске
(`node scripts/export-seed.mjs` → `server/data/seed.json`) и на них сайт откатывается, если API
недоступен.

| Что | Файл |
|---|---|
| Запасные контакты и бренд | `src/config/site.ts` |
| Запасные тарифы / прайс / работы / тексты | `src/data/*.ts` |
| Формулы калькулятора | `src/lib/calc.ts` |
| Подключение к API и откат на встроенные данные | `src/lib/content.tsx` |
| Сбор событий и Яндекс.Метрика | `src/lib/analytics.ts` |

Цены везде хранятся **базовыми для первого города** (Тюмень). Остальные города считаются
умножением на коэффициент из админки.

## Как устроен слайдер этапов

`src/components/sections/StageSlider.tsx`. Одна позиция `t` от 0 до 2:

- `t = 0` — вся комната черновая;
- `t = 1` — вся комната чистовая;
- `t = 2` — вся комната с мебелью.

Внизу лежит картинка текущего этапа, сверху — следующая, обрезанная по `clip-path` слева направо.
При переходе через `t = 1` нижняя картинка становится «чистовой», а верхняя — «с мебелью», причём в
этот момент обе стороны показывают один и тот же кадр, поэтому подмены не видно.

Стартовая позиция — 0.25: слева видна четверть чистовой отделки как «затравка», справа черновая.
Работает мышью, пальцем, стрелками с клавиатуры и кликом по трём подписям под картинкой.

Картинки — SVG в `public/stages/`, нарисованы в одной перспективе (точка схода 800×500), поэтому при
перетаскивании геометрия комнаты совпадает пиксель в пиксель. Заменяются на реальные фото объекта:
достаточно снять три кадра со штатива с одной точки.

## Что нужно от заказчика, чтобы снять заглушки

1. **Название компании, логотип, телефон, почта, мессенджеры, ИНН** → `src/config/site.ts`.
2. **Фотографии объектов** вместо `public/portfolio/*.svg` (генератор заглушек —
   `scripts/gen-portfolio.py`, после появления фото его можно удалить).
3. **Три кадра одной комнаты** для слайдера этапов: черновая, чистовая, с мебелью — со штатива с
   одной точки.
4. **Видеоотзывы** — сейчас три плитки-заглушки с прямой пометкой, что видео ещё не загружены.
5. **Сервер для админки.** Пока сайт на GitHub Pages, заявки складываются в `localStorage`.
   Чтобы заработали база, админка и Telegram — нужен VPS с Node, инструкция в [DEPLOY.md](DEPLOY.md).
   Токен Telegram-бота и номер счётчика Метрики вводятся в самой админке.
6. **Подтвердить цифры прайса и коэффициент по Москве.** Сейчас база — Тюмень, ×1.75 на Москву.
   Заказчик называл ориентир «50 м² ≈ 1 млн в Тюмени» — калькулятор это подтверждает (≈1,02–1,23 млн
   под ключ с материалами). Для Москвы он называл 3 млн, у нас выходит ~1,8–2,2 млн: либо поднять
   коэффициент до ~2.6, либо считать, что 3 млн — это дизайнерский уровень.
7. **Политика обработки персональных данных** — сейчас в футере честная пометка «документ в
   подготовке», ссылка `#privacy` ведёт на неё.

## Осознанно не сделано

- **Тёмная тема** — для лендинга-однодневки конверсии не добавляет, а поддержку усложняет вдвое.
- **Отдельные страницы услуг** (`/remont-novostroyki`, `/ceny` и т.д.) — нужны для SEO, но их имеет
  смысл делать после того, как утверждены тексты и появились фото. Каркас к этому готов: данные уже
  вынесены в `src/data/`, роутер добавляется без переписывания секций.
- **Карта офиса** — офиса пока нет, и сайт говорит об этом прямо, вместо того чтобы рисовать
  несуществующий адрес.
